# NextStopGuides

Bu depo, NextStopGuides markasına ait iki projeyi bir arada tutar.

| Klasör | Ne? | Nasıl açılır? |
|---|---|---|
| [`nextstopguides-web`](nextstopguides-web/) | 5 dilli (EN/TR/DE/FR/ES) seyahat landing page sitesi: dijital rehber satışı (Etsy/Shopier) + ortaklık bağlantıları (Airalo, Booking, GetYourGuide) | `index.html` dosyasına çift tıklayın |
| [`nextstopguides-game`](nextstopguides-game/) | Flutter ile yazılmış seyahat trivia/tahmin oyunu (web, iOS, Android) | Flutter kurulumundan sonra `flutter run -d chrome` |

Her klasörün içindeki `README.md` dosyası, o projeyi adım adım anlatır.
